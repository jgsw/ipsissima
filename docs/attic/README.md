# Attic

Code that is no longer wired into anything, kept because it explains why the
current thing looks the way it does.

- **`argdown-debt-plot.js`** — the ancestor of the Exposition view. It plotted one
  point per support edge, claim position against support position, so that the
  distance from the diagonal *was* the justificatory debt. It was retired in
  August 2026: what it was for — seeing a claim and its support far apart in the
  text — the Exposition view now shows directly, as a long line, with the
  reach-weighted stroke carrying the emphasis the plot carried with distance.
  Read its header comment before proposing a scatter view again.
